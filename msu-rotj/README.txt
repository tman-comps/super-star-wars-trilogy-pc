ORCHESTRAL MUSIC FOR SUPER RETURN OF THE JEDI (MSU-1 PACKS)

Put the .pcm files of an MSU-1 pack for Super Return of the Jedi in this folder
(not in msu/, which is Super Star Wars'), then pick
Music: Orchestral in Menu -> Options -> Audio while playing Jedi.

msu.txt is set up for the standard MSU-1 packs made for the "ssw3_msu" cartridge patch
by Conn & Relikk: copy that pack's ssw3_msu1-N.pcm files here as they are, no renaming.
You don't need the patch, the .msu file or a patched ROM.

How it works: track N is played from any file in this folder whose name ends in "-N.pcm",
and track N is the game's own song number N (the same numbering the cartridge patch uses).
Jingles play once, and the stage start fanfare finishes before the stage music starts.
Songs without a file just play the original SNES music.
