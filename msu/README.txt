ORCHESTRAL MUSIC FOR SUPER STAR WARS (MSU-1 PACKS)

Put the .pcm files of an MSU-1 pack for Super Star Wars in this folder, then pick
Music: Orchestral in Menu -> Options -> Audio.

msu.txt is set up for the standard MSU-1 packs made for the "ssw1_msu1" cartridge patch
by Conn & Relikk: copy that pack's ssw1_msu1-N.pcm files here as they are, no renaming.
You don't need the patch, the .msu file or a patched ROM.

How it works: track N is played from any file in this folder whose name ends in "-N.pcm",
and track N is the game's own song number N (the same numbering the cartridge patch uses).
Jingles play once, and the stage start fanfare finishes before the stage music starts.
Songs without a file just play the original SNES music.
