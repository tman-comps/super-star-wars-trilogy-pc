ORCHESTRAL MUSIC (MSU-1 PACKS)

Put the .pcm files of an MSU-1 pack for Super Star Wars in this folder, then pick
Music: Orchestral in Menu -> Options -> Audio.

msu.txt says which game song plays which track number. Track N is played from any file
in this folder whose name ends in "-N.pcm" (e.g. "ssw-5.pcm" or "Super Star Wars-5.pcm").
If your pack numbers its tracks differently, edit the third column of msu.txt.

Songs the game plays that aren't in msu.txt are written to unmapped.txt as you play,
so you can add them. Songs without a file just play the original SNES music.
