# Super Empire Strikes Back port: song -> MSU-1 track number
# Matches the cartridge MSU-1 patch by Conn & Relikk (ssw2_msu): its track N is the game's own
# song number N, so that pack's PCM files (ssw2_msu1-N.pcm) work as they are.
# The PCM for track N is any file in this folder ending in "-N.pcm".
#   songvar AAAA          where the game keeps its current song number (don't change)
#   song SS N [once]      game song SS (hex) plays track N; "once" = no looping (jingles),
#                         "finish" = no looping, and the next song waits until it ends
# Songs the game plays that are missing here get logged to unmapped.txt.
songvar 01EC
song 00  0 once     # lost a life
song 01  1 once     # opening crawl
song 02  2          # Hoth
song 03  3          # snowspeeder mission
song 04  4          # title screen
song 05  5          # Dagobah
song 06  6          # Wampa cave
song 07  7          # Bespin
song 08  8
song 09  9 once     # cutscene
song 0A 10 once     # cutscene
song 0B 11 once     # cutscene
song 0C 12 finish   # stage start fanfare
song 0D 13 once
song 0E 14 once     # cutscene
song 0F 15 once     # intro (LucasArts logo)
song 10 16 once     # intro
song 11 17
