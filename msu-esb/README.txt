ORCHESTRAL MUSIC FOR SUPER EMPIRE STRIKES BACK (MSU-1 PACKS)

Put the .pcm files of an MSU-1 pack for Super Empire Strikes Back in this folder
(not in msu/, which is Super Star Wars'), then pick Music: Orchestral in
Menu -> Options -> Audio while playing Empire.

msu.txt says which game song plays which track number. Track N is played from any file
in this folder whose name ends in "-N.pcm" (e.g. "sesb-5.pcm").
The numbers in msu.txt are a first guess: if your pack numbers its tracks differently,
edit the third column.

Songs the game plays that aren't in msu.txt are written to unmapped.txt as you play,
so you can add them. Songs without a file just play the original SNES music.
